# ProxyOS Alpha 0.1 刷机与测试说明

## 先在虚拟机测试

Alpha 0.1 是首次硬件测试版。请先在 PVE、VMware 或 VirtualBox 中创建一台
x86-64 虚拟机，添加两张网卡，再使用 UEFI 镜像启动。

默认分配：

- 第一张物理网卡：WAN，自动获取上级地址
- 第二张及以后网卡：LAN
- 只有一张网卡时：保留为 LAN，避免无法进入后台
- LAN 管理地址：`http://192.168.10.1`
- 用户名：`root`
- 初始密码：空

第一次登录后，请通过 SSH 执行 `passwd` 设置管理员密码。

## 写入实体磁盘前

1. 备份原系统和配置。
2. 确认目标磁盘，不要选错电脑系统盘。
3. 优先把镜像写入单独的 U 盘或备用 SSD 启动。
4. 保留显示器和键盘，或准备串口控制台。
5. 不要在生产网络中使用 Alpha 版本。

## Windows 写入

可使用 Rufus 或 balenaEtcher，选择：

- 新式设备：`ProxyOS-25.12.5-Alpha0.1-x86_64-UEFI.img.gz`
- 老式 BIOS：`ProxyOS-25.12.5-Alpha0.1-x86_64-BIOS.img.gz`

写入完成后，从该磁盘启动软路由。

## 首轮测试顺序

1. 只连接 LAN 口，确认电脑获得 `192.168.10.x` 地址。
2. 打开 `http://192.168.10.1`。
3. 确认“网络”页面中的物理网口、驱动、速率和角色正确。
4. 确认 WAN 能取得上级地址。
5. 在“Wi‑Fi”页面确认无线网卡状态；没有 AP 能力时应显示不可用。
6. 添加一个已知可用的 sing-box outbound JSON。
7. 在“设备”页面为测试手机绑定该节点。
8. 确认手机能够联网，并检查公网出口。
9. 删除或关闭节点，确认测试手机停止联网而不是回落到真实出口。
10. 重启系统，确认设备绑定仍然存在。

## 网口配置回滚

后台修改网口角色后，系统会等待 90 秒确认。如果后台无法重新连接，请不要
操作，系统会自动恢复修改前的 `/etc/config/network`。

## 已知限制

- 当前订阅只支持 sing-box JSON。
- Wi‑Fi 是否能建立稳定 AP 取决于无线芯片、固件和驱动。
- Alpha 默认关闭 LAN IPv6 广播，避免 IPv6 绕过代理。
- DNS 由 TUN 接管并按绑定节点建立 DoH 路径，但仍需在实体设备上做泄漏测试。
- 暂未提供在线升级、流量历史和自动节点测速。
