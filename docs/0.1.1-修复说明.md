# ProxyOS Alpha 0.1.1 修复说明

- 按参考图重做概览、设备、节点和 Wi-Fi 页面。
- 修复 rpcd 不接受顶层数组导致列表功能全部失败的问题。
- 修复 shell 默认参数多出一个 `}`，导致带参数的添加、绑定、开关和网口操作全部报错的问题。
- 设备扫描限制在 LAN，排除 WAN 网关、IPv6 邻居和无效 MAC。
- 网口角色读取 OpenWrt 实际桥接配置。
- 参数错误通过 JSON 返回到页面，不再只显示模糊的 ubus 错误码。
- 新增节点 TCP 延迟测试和路由器直连出口检查。
- 固件和 Web 资源版本升级为 `0.1.1-alpha`。
