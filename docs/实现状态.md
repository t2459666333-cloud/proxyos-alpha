| 设备自动发现 | 已实现 | 仅合并 LAN DHCP 租约和邻居表 |
| 每设备指定节点 | 已实现 | 固定 IPv4 对应 sing-box outbound |
| 系统默认/直连/阻止 | 已实现 | 页面和配置生成器均已接通 |
| 手动节点 | 已实现 | 表单参数或任意 sing-box outbound JSON |
| 节点 TCP 测试 | 已实现 | 返回延迟或明确的连接错误 |
| 节点失效阻断 | 已实现 | 不回落到真实直连 |
| sing-box 配置检查 | 已实现 | 检查失败不会替换运行配置 |
| 设备静态租约 | 已实现 | 绑定节点时写入 dnsmasq |
| Wi-Fi 检测 | 已实现 | 同时检查 PHY、驱动与 AP 模式 |
| Wi-Fi 一键开关 | 已实现 | 兼容硬件存在时启用，不删除配置 |
| 多网口分配 | 已实现 | 单 WAN、多 LAN、90 秒回滚 |
| sing-box JSON 订阅 | 已实现 | 更新时保留稳定节点 ID |
| Clash YAML/JSON 订阅 | 已实现 | 导入代理节点，不导入 Clash 规则 |
| Base64 与分享链接订阅 | 已实现 | 支持 SS、VMess、VLESS、Trojan、HY2、TUIC 等 |
| 节点原位编辑 | 已实现 | 使用完整 outbound JSON 安全编辑 |
| 自动节点与备用切换 | 已实现 | 每 5 分钟健康检测，按设备失效策略选择 |
| 每节点出口检测 | 已实现 | 临时隔离测试入口，不改变其他设备流量 |
| 无线详细设置 | 已实现 | SSID、密码、安全模式、频宽、功率、地区 |
| 访客 Wi-Fi | 已实现 | 独立网段、防火墙与客户端隔离 |
| 配置备份恢复 | 已实现 | 包含 ProxyOS 与 OpenWrt 网络相关配置 |
| 管理密码/日志/重启 | 已实现 | 由已登录的 rpcd 会话调用 |
| 在线升级 | 未实现 | 正式发布前加入签名与回滚 |
| 当前 x86 实机验证 | 进行中 | 0.2.0 镜像构建后继续测试 |
