# ProxyOS Alpha 0.1 实现状态

| 功能 | 状态 | 说明 |
|---|---|---|
| 自定义管理 UI | 已实现 | 登录、概览、设备、节点、订阅、Wi‑Fi、策略、网络、系统 |
| OpenWrt 登录保护 | 已实现 | 使用 rpcd/ubus 的 root 会话 |
| 设备自动发现 | 已实现 | DHCP 租约与邻居表 |
| 每设备指定节点 | 已实现 | 固定 IPv4 对应 sing-box outbound |
| 手动节点 | 已实现 | 常用协议表单 + 任意 outbound JSON |
| 节点失效阻断 | 已实现 | 不回落直连 |
| 节点稳定 ID | 已实现 | 连接参数哈希，不依赖显示名称和排序 |
| sing-box 配置检查 | 已实现 | 检查失败不替换运行配置 |
| 设备静态租约 | 已实现 | 绑定节点时写入 dnsmasq |
| DNS 跟随节点 | 已实现，待硬件验证 | TUN DNS 劫持 + 每节点 DoH detour |
| IPv6 防漏 | 已实现保守模式 | Alpha 默认关闭 LAN IPv6 |
| Wi‑Fi 检测 | 已实现 | 必须同时检测 PHY 和 AP 模式 |
| Wi‑Fi 一键开关 | 已实现 | 不删除无线配置和设备策略 |
| 多网口分配 | 已实现 | 单 WAN、多 LAN、90 秒回滚 |
| sing-box JSON 订阅 | 已实现 | 刷新保留稳定节点 ID |
| Clash/Base64 订阅 | 未实现 | 后续转换器模块 |
| 节点测速与主备切换 | 未实现 | 后续硬件测试版本 |
| 在线升级 | 未实现 | 正式发布前实现签名与回滚 |
| 实体 x86 验证 | 未完成 | 需要实际生成镜像并在目标硬件测试 |
