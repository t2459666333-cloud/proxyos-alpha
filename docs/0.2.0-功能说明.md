# ProxyOS Alpha 0.2.0 功能说明

- 四张核心页面严格沿用参考图的布局和视觉规范。
- 订阅自动识别 sing-box JSON、Clash YAML/JSON、Base64 与常见分享链接。
- 手动节点支持常用协议表单及完整 sing-box outbound JSON。
- 节点支持原位编辑、TCP 延迟测试、独立出口 IP 检测和定时健康检查。
- 设备支持系统默认、直连、指定节点、自动节点和禁止联网。
- 每台设备可设置备用节点，并选择保持断网、切换备用或切换直连。
- Wi-Fi 支持能力检测、一键开关、SSID/密码/安全模式/频宽/功率/地区设置。
- 访客 Wi-Fi 使用独立网段、防火墙区域和客户端隔离。
- 网络页面支持单 WAN、多 LAN、未使用网口和 90 秒安全回滚。
- 系统页面支持配置备份恢复、管理员密码、运行日志和重启。
